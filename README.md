# Kwate Farms & Agro Allied Industries Limited

Responsive static company website for the agribusiness based in Kazaure, Jigawa State, Nigeria.

## Deploy on Render
Create a **Static Site** connected to this repository:
- Branch: `main`
- Build command: leave blank
- Publish directory: `.`

No build step or server is required. The enquiry form opens WhatsApp with the visitor's message pre-filled; it does not store submissions.
